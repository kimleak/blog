# kimleak's blog

A small Tech & AI blog about making technology feel simple, exciting, and approachable.

Live site: https://kimleak.github.io/blog

## Run locally (optional)

```bash
bundle install
bundle exec jekyll serve
```

## Add a new post

Create a file in `_posts/` named `YYYY-MM-DD-slug.md` with Jekyll front matter, then commit and push.
