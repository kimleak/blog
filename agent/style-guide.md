# Style Guide

## The vibe
Write like you're texting a smart friend who happens to know a lot about tech.
Warm, curious, a little excited — never stiff or formal.

Think: "oh wow let me tell you about this thing I just learned"
Not: "this article will examine the implications of..."

---

## Voice rules

**Do this:**
- Use "you" and "we" — talk to the reader directly
- Start sentences with "So", "But", "And" when it flows naturally
- Use contractions: it's, you'll, don't, here's
- Ask questions to keep the reader curious: "sound familiar?"
- Use short sentences. One idea per sentence.
- Use analogies for complex things — compare tech to everyday life

**Never do this:**
- Never say "In conclusion" or "To summarize"
- Never use buzzwords: leverage, synergy, ecosystem, paradigm
- Never use passive voice: "it was decided" → "we decided"
- Never write more than 4 lines in one paragraph — break it up
- Never use more than 2 exclamation marks per article

---

## Article structure

Every article follows this shape:

1. **Hook** (2–3 sentences) — a question, a surprising fact, or a relatable moment
2. **What it is** — explain the topic in plain language
3. **Why it matters** — so what? why should the reader care?
4. **How it works** — simple explanation, use an analogy
5. **What's next** — what can the reader do with this info?
6. **One-line closer** — end on a thought, not a summary

---

## Language level
- Write for someone who uses tech every day but isn't a developer
- If you use a technical term, explain it in the next sentence
- Good test: would a curious 20-year-old with no CS background get it?

---

## Length
- Default: 500–700 words
- Deep dive (when requested): up to 1200 words
- Never pad. If you've said what needs to be said, stop.
